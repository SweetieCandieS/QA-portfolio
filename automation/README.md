# Автотесты: Python + Selenium

Автотесты на Python с использованием Selenium WebDriver, выполнены в рамках курса по автоматизации тестирования.

## Список тестов

| Файл | Что покрывает |
|---|---|
| `test_register_upload.py` | Форма регистрации (Register.html): обязательные поля, дата рождения через Select, пароль, загрузка файла, скролл и отправка формы |
| `test_alerts.py` | Работа с JS-алертами (Alert, Confirm, Prompt) и переключение между несколькими вкладками браузера |
| `test_espocrm_task_flow.py` | EspoCRM (demo-сервер): логин, создание задачи, проверка статуса и кнопки массового обновления, удаление задачи |
| `test_saucedemo_cart.py` | SauceDemo: логин, добавление 3 товаров в корзину, проверка их количества через `find_elements` |

## Особенности запуска `test_register_upload.py`

Тесту нужна картинка для загрузки в поле «Photo» — она не включена напрямую в код и должна лежать рядом со скриптом:

```
automation/
├── test_register_upload.py
└── picture/
    └── test-photo.jpg
```

Также на демо-сайте селектор **Country** не содержит реальных вариантов (только плейсхолдер) — из-за этого форма не проходит валидацию, и переход на следующую страницу после Submit не происходит. Это известное ограничение самого сайта, а не баг теста — подробности в комментариях внутри файла.

## Особенности запуска `test_espocrm_task_flow.py`

⚠️ Этот тест требует локальной установки VPN-расширения Browsec и ручного шага при запуске — путь к расширению нужно заменить на свой (см. ниже). Быстрее всего оценить этот тест — открыть код и прочитать логику, а не запускать локально.

Этот тест — **не полностью автоматический**: demo-сервер EspoCRM недоступен без VPN, поэтому скрипт устанавливает браузерное расширение Browsec и на середине выполнения останавливается на `input()`, ожидая, пока VPN включат вручную. При запуске нужно:

1. Дождаться сообщения в консоли `Включить VPN и нажать Enter`.
2. Вручную открыть попап расширения Browsec и включить VPN.
3. Вернуться в консоль и нажать Enter, чтобы тест продолжился.

Также в коде указан абсолютный путь к расширению (`path_to_extension`), взятый с конкретного компьютера — при запуске на другой машине путь нужно заменить на свой (найти локальную папку расширения Browsec в директории профиля Chrome).

## Как запустить

1. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Запустить нужный тест, например:
   ```
   python test_alerts.py
   ```

## Требования

- Python 3.x
- Google Chrome (тесты используют `webdriver.Chrome()`)
- Зависимости из `requirements.txt`
