# Чек-лист: Organizer

Веб-приложение для управления задачами (клиенты → проекты → задачи), с статусами, дедлайнами, типами работ, оценкой времени, комментариями и перемещением задач между проектами.

## Функциональность

### 1. Название задачи

- Ввод данных (см. Таблицу №1)
- Изменить название задачи кнопкой "Actions"
- Сохранение кнопкой интерфейса ("OK"/"Save")
- Сохранение кнопкой ENTER
- Клик за пределами поля с редактированием задачи
- Выйти из редактирования задачи кнопкой ESC
- Изменить название существующей задачи
- Удалить название существующей задачи
- Одинаковые названия задач для одного клиента в одном проекте
- Одинаковые названия задач для одного клиента в разных проектах
- Одинаковые названия задач для разных клиентов
- Просмотреть детали задачи на кнопку "View more"
- Действия в списке:
  - применить сортировку
  - применить фильтры
  - создать нового клиента/проект

### 2. Status

- Создать статус с типом "open"
- Создать статус с типом "completed"
- Добавить статус
- Удалить статус
- Изменить название существующего статуса
- Изменить цвет
- Ввод данных (см. Таблицу №1)
- Сохранение кнопкой ENTER
- Клик за пределами поля с редактированием статуса
- Выйти из редактирования статуса кнопкой ESC
- Изменить статус вручную
- Изменить статус кнопкой "Change Status"
- Изменить статус у 1 задачи
- Применить сортировку
- Применить фильтры
- Создан новый клиент/проект/задача
- Выбор статусов:
  - список пустой
  - в списке только 1 активный статус
  - в списке только 1 завершённый статус
  - в списке по 1 активному и завершённому статусу
  - в списке много статусов

### 3. Deadline

- Оставить поле пустым
- Ввести дату вручную
- Выбрать прошедшую дату
- Выбрать дату далёкого прошлого/прошлый век
- Срок выполнения больше 3 дней
- Срок выполнения через 3 дня
- Срок выполнения через 1 день
- Выбрать дату далёкого будущего
- Изменить цвет даты
- Очистить дату кнопкой "clear"
- Выставить сегодняшнюю дату кнопкой "today"
- Отменить выбор даты кнопкой "cancel"
- Отменить выбор даты кликом за пределами календаря
- Отменить выбор даты нажатием на крестик
- Отменить выбор кнопкой ESC
- Сохранение кнопкой "OK"
- Сохранение кнопкой ENTER
- Выбор месяца/года нажатием/двойным нажатием в верхней части календаря "March 2019"
- Вернуться к прошлому месяцу
- Перейти на следующий месяц
- Вернуться к прошлому месяцу стрелками с клавиатуры
- Перейти на следующий месяц стрелками с клавиатуры
- Удалить дату
- Применить сортировку
- Применить фильтры
- Создан новый клиент/проект/задача

### 4. Type of Work

- Добавить тип
- Удалить тип
- Переименовать тип
- Изменить тип по умолчанию
- Изменить тип на архивный
- Изменить архивный тип на действующий
- В списке много типов
- В списке только тип "Non-Billable"
- В списке только тип "Billable"
- В списке 1 тип "Non-Billable" и 1 тип "Billable"
- В списке много позиций
- Список пустой
- Изменить название существующего типа
- Ввод данных (см. Таблицу №1)
- Сохранение кнопкой ENTER
- Сохранение кнопкой интерфейса ("OK"/"Save")
- Клик за пределами поля с редактированием типа работы
- Выйти из поля кнопкой ESC
- Выбрать задачи с одним типом работы
- Выбрать задачи с разными типами работы
- Применить сортировку
- Применить фильтры
- Создан новый клиент/проект/задача

### 5. Estimate

- Ввод данных (см. Таблицу №1)
- Изменить время
- Удалить время на иконку крестик
- Клик за пределами поля времени
- Выйти из поля кнопкой ESC
- Оставить поле пустым
- Сохранение кнопкой ENTER
- Сохранение кнопкой интерфейса ("OK"/"Save")
- Ввести 0
- Ввести 00:00; 00:01; 00:10; 01:00
- Ввести 9998:00; 9998:59; 9998:99; 9999:00; 9999:01; 10000:00
- Полоса прогресса:
  - Estimate равен reported time
  - Estimate больше reported time
  - Estimate меньше reported time
  - Изменить reported time (если возможно)
  - Удалить reported time (если возможно)

### 6. Description

- Проверить лимит:
  - Ввести 1 символ
  - Ввести 1999 символов
  - Ввести 2000 символов
  - Ввести 2001 символ
- Проверить скролл:
  - Ввести 250 символов
  - Ввести 499 символов
  - Ввести 500 символов
  - Ввести 501 символ
- Описание:
  - ввод данных (см. Таблицу №1)
- Сохранение кнопкой интерфейса ("OK"/"Save")
- Сохранение кнопкой ENTER
- Клик за пределами поля с редактированием описания
- Выйти из описания кнопкой ESC
- Закрытие кнопкой интерфейса (крестик/отмена)

### 7. Comments

- Ввод данных (см. Таблицу №1)
- Только один комментарий
- Одинаковые комментарии
- Много комментариев
- Оставить больше 100 комментариев
- Комментарии только от одного пользователя
- Комментарии от разных пользователей
- Удалить комментарий
- Редактировать комментарий
- Ctrl V + Ctrl C
- Выбрать комментарии
- Сортировать комментарии (сначала свежие/сначала старые)
- Комментарии от пользователей с разными часовыми поясами
- Комментарии от пользователей с одинаковыми часовыми поясами
- Длинный комментарий
- Короткий комментарий

### 8. Move to

- Переместить задачу к другому клиенту
- Переместить задачу к другому клиенту, где в проекте уже есть задача с таким названием
- Переместить задачу в проект с таким же названием, но к другому клиенту
- Переместить задачу в другой проект одного и того же клиента
- Переместить задачу к клиенту, где уже есть задача с таким же названием, но в другом проекте
- Переместить задачу в другой проект одного и того же клиента, где в проекте уже есть задача с таким названием
- Переместить задачу в тот же проект одного и того же клиента
- Переместить задачу с открытым статусом в архивный проект
- Переместить задачу с завершённым статусом в архивный проект
- Переместить задачу с завершённым статусом из архивного проекта
- Проверить скроллы "Customer" и "Project":
  - Создать много клиентов
  - Создать много проектов

### 9. Общее

- Изменить цветовую схему всех элементов на зелёную
- Редактировать задачу, если есть право "Manage Scope of Work"
- Редактировать задачу при отсутствии права "Manage Scope of Work"
- Проверить, что сессия равна 1 часу
- Время сессии 59 минут
- Время сессии 1 час 1 минута
- Выполнить любое действие по истечении 1 часа
- Выполнить любое действие, если аккаунт заблокирован
- Попытка залогиниться с заблокированного аккаунта
- Проверить действия с задачами:
  - Изменить статус у нескольких задач
  - Изменить статус у всех задач
  - Выбрать задачи с одним статусом
  - Выбрать задачи с разными статусами
  - У всех выбранных задач должен измениться статус
  - У части выбранных задач должен измениться статус
- Проверить работоспособность кнопки "Add New":
  - Добавить нового клиента
  - Добавить новый проект
  - Добавить новую задачу
  - Применить фильтр и добавить клиента/проект/задачу
- Проверить скролл в меню слева:
  - Добавить много клиентов
  - Добавить много проектов
  - Скрыть все проекты одного/каждого из клиентов
- Проверить работоспособность иконки с шестерёнкой рядом с названием клиента в левой части
- Проверить поле ввода для поиска клиента:
  - Наложение текста на плейсхолдер
  - ввод данных (см. Таблицу №1)
  - Совпадение при вводе первой буквы названия клиента
  - Совпадение при вводе двух первых букв названия клиента
- Проверить работоспособность иконки с шестерёнкой рядом с названием клиента вверху центральной части

### 10. Конкурентные ситуации

**Пользователь А и пользователь Б одновременно работают с одной задачей:**

| Пользователь А | Пользователь Б |
|---|---|
| Удалить задачу | Удалить задачу |
| | Изменить название задачи |
| | Переместить задачу |
| | Изменить статус задачи |
| | Оставить комментарий к задаче |
| | Изменить дедлайн |
| | Изменить описание к задаче |
| | Изменить тип работы задачи |
| | Изменить Estimate задачи |
| | Закрыть и заново открыть задачу |
| | Выделить задачу |
| | Нажать кнопку "View more" для просмотра деталей задачи |
| Переместить задачу | Удалить задачу |
| | Изменить название задачи |
| | Переместить задачу |
| | Изменить статус задачи |
| | Оставить комментарий к задаче |
| | Изменить дедлайн |
| | Изменить описание к задаче |
| | Изменить тип работы задачи |
| | Изменить Estimate задачи |
| | Закрыть и заново открыть задачу |
| | Выделить задачу |
| | Нажать кнопку "View more" для просмотра деталей задачи |

**Пользователь А и пользователь Б одновременно вносят одинаковые изменения в одну задачу:**
- изменить название задачи
- изменить статус задачи
- изменить описание задачи
- изменить дедлайн задачи
- изменить тип работы задачи
- изменить Estimate задачи
- оставить разные комментарии
- оставить одинаковые комментарии

**Прочие конкурентные сценарии:**
- Пользователь А удаляет проект, пользователь Б создаёт в нём задачу
- Пользователь А удаляет проект, пользователь Б перемещает в него задачу
- Пользователь А удаляет проект, пользователь Б изменяет его название
- Пользователь А удаляет клиента, пользователь Б создаёт в нём проект
- Пользователь А и пользователь Б одновременно перемещают задачи с одинаковым названием в один проект к одному клиенту
- Пользователь А и пользователь Б одновременно создают задачи с одинаковым названием в одном проекте у одного клиента
- Пользователь А и пользователь Б одновременно создают клиентов с одинаковым названием
- У пользователя А есть право "Manage Scope of Work", и он редактирует задачу, в это же время пользователь Б снимает с него это право
- Пользователь А удаляет пользователя Б, пользователь Б в это время создаёт новую задачу
- Пользователь А блокирует пользователя Б, пользователь Б в это время добавляет описание к задаче
- Пользователь А переименовывает клиента, пользователь Б в это время создаёт новый проект у этого клиента
- Пользователь А переносит проект к другому клиенту, пользователь Б в это время создаёт новую задачу в этом проекте

Применяется ко всем текстовым полям, где в чек-листе есть отсылка «см. Таблицу №1»:

- На русском языке
- На английском языке
- Комбинация разных языков
- Цифры
- Отрицательное число
- Дробное число (0,5; 0.5; 1/2)
- 0.
- Символы
- Эмодзи
- Комбинация языков, символов, цифр, эмодзи
- Верхний и нижний регистры
- Пустой ввод
- Только пробел
- Минимальная длина ввода
- Максимальная длина ввода
- Ctrl V + Ctrl C
- Ссылка
- XSS-инъекция
