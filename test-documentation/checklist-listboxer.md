# Чек-лист: ListBoxer

Десктопное приложение для работы со списком значений (буквенных/числовых) с сортировкой, фильтрацией и сохранением в файл.

## 1. Общее

- Соответствие основных требований спецификации на наличие их в программе
- Установка программы
- Установка в разные директории
- Создание ярлыка на рабочем столе
- Создание ярлыка в меню Пуск
- Полное удаление программы
- Частичное удаление программы с сохранением данных
- Запуск программы
- Названия меню/кнопок/программы
- Открытие больше одного окна программы
- Проверить версию программы

## 2. Работоспособность кнопок меню

- **File**
  - Выйти из программы кнопкой Exit
- **Edit**
- **Help**
  - Получение справки кнопкой "Contents"
  - Получение сведений о программе кнопкой "About ListBoxer"
- Горячие клавиши
- TAB
- Закрытие программы на крестик
- Сворачивание программы кнопкой "—"
- Сворачивание программы нажатием на иконку программы на панели Пуск
- Получение справки о программе нажатием на знак "?"

## 3. Поле ввода

- На русском языке
- На английском языке
- Комбинация разных языков
- Цифры
- Отрицательное число
- Дробное число (0,5; 0.5; 1/2)
- 0.
- Символы
- Эмодзи
- Комбинация языков, символов, цифр, эмодзи
- Верхний и нижний регистры
- Только пробел
- Пустой ввод
- Минимальная длина ввода
- Максимальная длина ввода
- Ctrl V + Ctrl C
- Ссылка

## 7. Сохранение

- При выходе из программы кнопкой "Exit" через меню "File"
- При выходе из программы закрытием на крестик
- Кнопкой "Save As" через меню "File"
- Пустого файла
- В разные директории
- Сохранение маленького файла меньше 3 записей в списке
- Сохранение большого файла больше 200 записей в списке

## 8. Открытие файла

**Кнопкой "Open" через меню "File":**
- файлов разного типа
- только что сохранённого файла
- пустого файла

## 9. Список

- Добавление записей кнопкой "Add to List"

- Наличие скролла при создании большого списка
- Минимально допустимый список — 1 запись
- Максимально допустимый список — 100/200/300 записей
- Добавление одинаковых записей
- Очистка списка кнопкой "Clear List"
- Очистка только одной записи кнопкой "Clear List"
- Отмена очистки списка кнопкой "Undo" через меню "Edit"
- Добавление записи сразу после отмены очистки списка кнопкой "Undo"
- Удаление введённой записи кнопкой "Undo" через меню "Edit"
- Многократное применение "Undo" для отмены введённых записей
- Добавление новой записи сразу после удаления старой кнопкой "Undo"
- Вырезать запись кнопкой "Cut" через меню "Edit"
- Скопировать запись кнопкой "Copy" через меню "Edit"
- Вставить запись кнопкой "Paste" через меню "Edit"
- Вырезать/скопировать/вставить горячими клавишами
- Внести изменения в сохранённый файл
- Изменение счётчиков при добавлении записей
- Изменение счётчиков при удалении записи
- Изменение счётчиков при добавлении одинаковых записей
- Изменение счётчиков при создании маленького списка
- Изменение счётчиков при добавлении большого количества записей
- Изменение счётчиков при внесении изменения в сохранённый файл
- Изменение счётчиков при смене режима ввода "Numeric"/"Alphabetic"/смешанный
- Изменение счётчиков при изменении сортировки
- Изменение счётчиков при изменении фильтра
